# Wizard of WASD (Atari Lynx)

Wizard of WASD for Atari Lynx, written in C and compiled with llvm-mos.



<img src="wizard-0000.png" height=306/>

The full game is playable until the end, but needs some polishing.



It is a very simple adventure/puzzle game.



The game is based on the original 10-Line BASIC game by Randy Gill, for Atari 8-bit. Info can be found here:
https://angrydill.com/wasd/
